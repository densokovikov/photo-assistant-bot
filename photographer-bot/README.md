# Telegram-помощник по фотографии

Каждый день в 10:00 по московскому времени бот присылает:

- одного фотографа из таблицы `photographers-table.html`;
- один полный урок из курса `portrait-course.html`: теорию, все практические задания, итог, советы и источник.

Фотографы и 30 уроков идут по порядку и после окончания начинаются сначала. Курс начинается с урока 1 — «Лицо, оптика и перспектива», затем приходит урок 2 и так далее.

## Настройка

1. Дважды нажмите `setup.command`.
2. Вставьте новый токен от BotFather. Символы при вводе не отображаются — это нормально.
3. Когда окно попросит, откройте своего бота в Telegram и отправьте ему `/start`.
4. После сообщения «Готово» ежедневный запуск установлен.

Для проверки сразу дважды нажмите `send-now.command`.

Для отправки ровно в 10:00 Mac должен быть включён и подключён к интернету. Если нужна независимая работа при выключенном компьютере, бота потребуется разместить на сервере.

## Облачный запуск через GitHub Actions

Workflow `.github/workflows/daily-telegram.yml` отправляет сообщение ежедневно в 10:00 по часовому поясу `Europe/Moscow`, даже если Mac выключен. В приватном репозитории нужно создать два Actions secret:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `TELEGRAM_CHAT_ID` — ID зарегистрированного личного чата.

Токен и chat ID не записываются в репозиторий. Номер карточки определяется календарной датой, поэтому облачному запуску не нужен изменяемый файл состояния.

Токен хранится только локально в скрытом файле `.env` с закрытыми правами. В Telegram-чат или другие сообщения его отправлять не нужно.

## Данные

- `data/photographers.json` — данные 341 строки таблицы;
- `data/assignments.json` — 30 полных уроков курса;
- `../photographers-and-course.xlsx` — те же данные в Excel на двух листах.

Состояние очереди и зарегистрированный Telegram chat ID сохраняются в `state.json`.
