# Портрет: практика, культура, видение

[Открыть курс](https://densokovikov.github.io/photo-assistant-bot/) · [Каталог фотографов](https://densokovikov.github.io/photo-assistant-bot/photographers-table.html)

Курс содержит 34 темы для практикующих фотографов, визуальный атлас исторических работ и подборку выступлений. Все изображения встроены в HTML.

В заголовке каждой темы есть кнопка «Отметить просмотренным». Повторное нажатие снимает отметку. Просмотренные темы отмечаются в меню; счётчик показывает количество и процент просмотренных тем. Прогресс сохраняется в браузере после перезагрузки страницы. На других устройствах и в других браузерах прогресс отдельный.

## Публикация

Workflow `.github/workflows/pages.yml` публикует сайт через GitHub Pages после изменения HTML в ветке `main`. В опубликованный сайт попадают только курс и каталог фотографов. Исходники Telegram-бота не входят в пакет сайта.
